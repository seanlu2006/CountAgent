# CountAgant

**一個由 Claude Code 驅動的個人記帳 agent。**

市面上的記帳 App 太複雜——記一筆要點七八下、選分類、填欄位，最後還撈不出真正想看的數字，於是記兩週就放棄。
CountAgant 反過來做：**捕捉端笨到極點，判斷端全部交給 AI**。你在外面對 Siri 說一句「午餐 120」，
回到電腦說一聲「整理」，剩下的分類、補欄位、算預算、產財報，全由 agent 完成。

---

## 核心設計

> **對抗怠惰是最高原則。** 記帳失敗從來不是因為功能不夠，是因為「當下記錄」這件事太麻煩。

因此系統把**捕捉**與**整理**徹底拆開：

| | 捕捉 | 整理 |
|---|---|---|
| 在哪 | iPhone，任何地方 | 電腦，有空時 |
| 誰做 | 你，2 秒一句話 | Agent，全自動 |
| 要多聰明 | 笨到極點（純文字附加） | 很聰明（語意解析 + 判斷） |

## 運作流程

```
iPhone ──「嘿 Siri，記一筆」──▶ 說「午餐 120」
                                    │
                    寫入 iCloud inbox.txt（帶時間戳）
                                    │
                             自動同步到 Mac
                                    │
          你說「整理」──▶ Agent 逐行解析 ──▶ ledger.csv
                                    │
                    ┌───────────────┼───────────────┐
                  月報            季度財報         視覺化儀表板
```

**Agent 自動補齊的欄位**：日期、收支類型、分類、付款方式、品項。
你只需要丟一句自然語言，連格式都不用管。

## 功能

- **零摩擦記帳** — iOS 捷徑 + Siri 語音，離線可用，時間戳自動帶入
- **智慧解析** — 由 LLM 判斷語意，非死板正則。「昨天宵夜 97」會正確歸到昨天
- **去重防呆** — iCloud 同步時效可能把舊資料帶回，以歸檔比對逐字去重
- **多維報表** — 月報、季度財報（含儲蓄率、固定 vs 變動支出）、HTML 儀表板
- **預算追蹤** — 預算 vs 實際，依時間進度折算，超支自動標記
- **對帳能力** — 與信用卡帳單比對，找出漏記或付款方式歸錯
- **電子發票匯入** — 支援財政部載具 API 與 CSV 匯入（欄名不拘、Big5/UTF-8 自動判讀）
- **成本分析** — 追蹤食材消耗速度，換算自煮 vs 外食的真實單餐成本

## 專案結構

```
CountAgant/
├── CLAUDE.md              # Agent 的行為定義（本專案的核心）
├── data/
│   ├── ledger.csv         # 主帳本
│   ├── categories.md      # 分類定義
│   ├── budget.md          # 預算與儲蓄目標
│   └── food_notes.md      # 食材成本追蹤
├── scripts/
│   ├── report.py          # 月報
│   ├── quarterly.py       # 季度財報（可輸出 Markdown）
│   ├── dashboard.py       # HTML 視覺化儀表板
│   ├── import_csv.py      # 電子發票 CSV 匯入
│   └── fetch_invoices.py  # 財政部載具 API 抓取
└── reports/               # 產出的報表
```

## 快速開始

```bash
python3 scripts/report.py              # 本月月報
python3 scripts/report.py 2026-08      # 指定月份
python3 scripts/quarterly.py 2026Q3    # 季度財報
python3 scripts/quarterly.py 2026Q3 --md   # 另存 Markdown
python3 scripts/dashboard.py           # 產生並開啟視覺化儀表板
```

**記帳**則不用指令——直接跟 Claude Code 說「午餐 120」或「整理」即可。

## 技術特點

- **純標準函式庫**，無需 pip 安裝任何套件
- **CSV 為單一事實來源**，可用 Excel 直接開、易於備份與遷移
- **行為定義寫在 `CLAUDE.md`**，Agent 的判斷邏輯是可讀、可改的自然語言，不是寫死的程式
